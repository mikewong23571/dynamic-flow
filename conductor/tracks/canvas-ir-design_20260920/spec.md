# Spec — 画布与 JS 子集 IR 设计收敛

类型：文档 / 架构调整。用户已明确要求简化设计、移除不需要功能、将当前设计放入 docs 并原样归档原始文件；本指示授权同步产品定义、技术方向与交互指南，无需重复确认。

## 目标

- 以统一 JS 语义子集 IR 定义工作流，由 runtime 执行；画布与 Agent 编辑相同定义。
- 人类主要通过拖拽节点、连线、节点配置和自然语言修改；JS 可选只读查看。
- 保留真实运行、样本试验、结果比较与分别采用方法/产物的核心闭环。
- 移除任意 JS 分析、源码位置绑定、核心代码编辑/Diff、图代码双向转换以及无需求的通用平台设计。
- docs 下提供当前简化设计与阅读入口；docs/archive 下保存原始 v2 字节不变的副本。
- 同步 Conductor 与历史 Spike 的适用范围说明，避免后续 coding agent 从旧推荐继续实现。

## 验收

原稿 SHA-256 一致；当前设计与项目上下文一致；本地 Markdown 链接可解析；归档和历史记录有明确状态；不将新 IR/runtime 描述为已经实现。
