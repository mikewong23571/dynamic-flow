# 工作项聊天引用流水线

## 目标
用户在现有工作项Composer输入 /，通过 /pipeline 命令与自动补全选择真实流水线的保存版本，添加简短指导后发送。引用可预览/移除，随会话草稿保存；模型接收经服务器核对的固定ID、版本及方法合同，用户消息保留可读引用。引用只提供上下文，不自动执行。Assistant沿现有check_workspace反馈检查自身方案。

## 非目标
不实现通用@语言/附件平台，不修改正式方法业务逻辑，不以名称猜版本，不改模型配置，不在源码写CVE业务。

## 改动点与影响
shared引用类型；workitem Assistant解析与持久上下文；HTTP接线；Composer插槽、现有Popover/Command选择、MethodPreview；会话草稿隔离和消息呈现。顺带将逐项call改为先选本条再复制，避免整批N²复制。

## 验收
真实保存版本引用、无效/归属/归档拒绝、模型固定合同、旧消息与引用不可漂移。浏览器键盘/选择/预览/移除/发送、切换会话和刷新草稿、失败保留引用；1440及1024截图。原完成结果和工作项业务状态不变化。
