# 首页与全局列表只展示顶层工作项

2026-10-29，用户已授权修复。沿用本仓conductor/tracks格式，由主代理在既有独立工作区实施，不使用子代理，不操作托管。

## 目标

首页继续列表与全局工作项列表只展示无parentId的工作项，搜索/状态数量/总数/分页统一顶层口径。父项利用现有子项完成数显示简洁进度；父项内部仍能管理子项，子项直接地址和按id来源读取保留。

## 非目标

不删除/迁移子项、不改父子归属/结项/运行和批次语义，不新增混排开关或层级导航平台。不部署4320/4321，不修改托管数据。

## 改动点

server/work-items/queries.ts增加显式view=roots，只在该范围内先筛顶层再统计/搜索/分页；client WorkItems查询使用此范围，复用已有Table/Badge呈现childCount/completedChildCount，WorkHome.css局部排列；必要模块/HTTP/浏览器测试及最近指南。

## 影响域与验收

全局UI使用明确roots查询；原无范围API、ids查询、parentId/rootId子项范围保持原语义，避免来源检查/批次调用丢子项。用父项/直属/孙项/排除/已完成等真实临时数据验证计数、分页、搜索及跨范围缓存隔离；两尺寸实际浏览首页/列表/父项子项管理，确认子项仍可打开。继承访问合同及现成控件，不改变页面骨架。
