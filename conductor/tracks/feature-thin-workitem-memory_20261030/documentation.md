# 实施说明

工作项保留5个业务方法调用；数据整理、事实汇合与交付整理是3个普通确定性方法，研究与仓库核查继续引用原正式方法。业务逻辑只在用户保存的Definition中，通用源码没有漏洞领域分支。不新增执行器，不通过画布折叠掩盖根定义。

工作区与方法浏览器使用运行概要，原始正文按固定来源读取；大表详情按固定交付与记录编号读取。概要明确标记遗漏并禁止直接作为运行输入。来源检查只缓存当前来源，导航记录保留引用；离开工作项释放数据面板，仅保留浏览、选择和草稿状态。既有手工交付配置通过valueFields读取字段名，CLI业务读取明确使用view=full及runIds。

全部改动先在独立工作区、用户数据副本、4332/4333验证。托管切换保留556条完成执行和2条在途输入，恢复原批次。业务做法通过正式API更新，原事实与固定来源不改写；新运行只重组现有输入，不补造研究或仓库判断。

测试、实际副本、浏览器操作与托管对账分开记录，见evidence.md。当前仍按原文件格式整体原子保存，未解决大Work长期归档与所有未来规模的成本，不据此扩大原型架构。
