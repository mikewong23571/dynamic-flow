# 薄工作项与有界页面数据

## 目标

当前CVE工作项由21个节点收敛为表达业务职责的5个固定方法调用：整理输入、补充事实、确定核查依据、核查仓库、整理交付。原确定性规则下沉为3个可复用方法，研究/核查仍引用原固定方法；不只是画布折叠，不新增Agent或重跑原队列。

浏览器默认只读取流程/运行概要、可见表格字段与来源、聊天正文及活动概要。详情/原始输入/活动按精确来源按需读取，较大值分页预览，不把遗漏当空值。原工作区约128MB磁盘数据不能整体发往浏览器。用实际副本测响应大小/浏览器内存，验证多项切换、查询、分页、详情、固定来源和对话编辑。

## 非目标

不改历史Run/原始事实/完成条件，不迁移数据库，不新增业务状态机/执行器，不按CVE在通用src分支，不固定所有工作项的节点数量。新方法的输入输出与当前交付等价，未授权的新研究不执行。

## 改动点

- server/work-items：概要投影、交付可见字段、精确记录/输入内容读取。
- server/flow、files、runs：运行概要投影、单值内容读取；避免只读一个Run却复制整Work。
- client：遗漏详情显式按需读取，有界内容预览；保留原控件和实际错误；减少隐藏数据副本。
- 当前工作项：实际方法提取与5节点编排，原界面模板/交付保留并真实核验。

## 影响域

workspace HTTP/写回/Assistant共用状态、运行来源检查、输入编辑与声明UI、原子保存。概要字段必须显式标记未加载；业务命令始终从服务器读取原值。最小输入为稳定ID/版本/来源，输出为概要或指定内容页；失效引用/冲突/错误不可用空值代替。
