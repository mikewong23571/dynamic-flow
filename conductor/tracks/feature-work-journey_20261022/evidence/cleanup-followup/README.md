# 数据清理后的入口与列表修正

用户清理旧测试数据后反馈两个实际问题：浏览器保存的已打开测试流水线仍请求不存在的work.json；未定义状态标签使用empty类名，误套整页空状态180px最小高度。

修正：快照仅在目标work.json确实缺失时返回404/WORK_NOT_FOUND；客户端移除失效入口，当前项消失时回到流水线列表。其它读取失败保留入口并显示错误。整页空状态布局改用empty-state，状态empty不再承载页面布局。

本地Playwright在当前dev源码验证，无业务写入：注入一个已删除入口和一个真实保留入口，1440/1024均自动清理失效入口并保留真实入口，页面回到6条流水线列表，无ENOENT；6行高度均约69px。另模拟500临时错误，入口仍保留且错误可见。已查看1024截图，无异常高度和横向溢出。结果见results.json和两尺寸截图。typecheck:app通过。

测试数据移出应用至 /home/mike/.local/share/flowcraft-cleanup/ 下，清单与恢复备份留在那里；未删除真实业务方法或浏览器本地编辑草稿。
