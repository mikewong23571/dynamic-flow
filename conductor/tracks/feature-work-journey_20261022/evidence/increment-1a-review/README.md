# 增量 1A 独立复核

2026-10-22。在实现与构建冻结后，用本地 Playwright 对 4320 的真实 CVE 工作项做只读检查。没有提交启动、改变业务材料或调用模型；[检查脚本](check.cjs)拒绝所有非 GET/HEAD API 请求，[检查记录](checks.json)为两尺寸均零写入、零页面异常、无横向溢出。

核验：入口明确为“运行流水线”；当前方法与保存版本可见；4 份真实材料默认只列简短摘要，正文按需挂载；取消一条后已选数及启动数量同步，清空后禁止启动；取消返回原工作项。保存版本为真实 adopted Definition ID，非提交时重新猜测版本。

代码复核覆盖 materialIds 服务端验证、固定工作项材料快照、页面勾选提交顺序与保存版本。取消再勾回后按可见列表顺序提交，避免点击顺序暗改执行顺序。现有 Assistant 本来就按节点 materialIds 过滤 prompt 材料；此次无需扩改模型或执行调度器。
