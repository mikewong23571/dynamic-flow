# 工作区性能修复

## 目标
以现有大工作项的独立数据副本实测，减少未变内容的重复读取、传输与渲染；避免 Assistant 逐 token 保存整份运行历史造成对话迟迟不结束。保留输入、成果、来源、历史和真实错误。

## 非目标
不改变业务流程或视觉布局，不重跑研究，不引入数据库或通用平台，不迁移旧数据。

## 改动点及影响域
files 的投影读取；方法目录与工作项工作区读取；工作区 HTTP 条件请求、前端刷新；Assistant 流式消息写入合并。涉及文件副本隔离、磁盘版本变化、发布读回、取消与最终落盘。按实际测量决定必要的额外页面读取精简。

## 验收
记录真实副本的首载、未变刷新、响应字节和浏览器交互；未变刷新应无需全量 JSON。定向模块覆盖外部磁盘变化、调用方修改隔离、最终文本完整、失败/取消及版本冲突。独立浏览器操作搜索、分页、详情、输入与流程保持可用；部署前保证在途执行不被中断。
