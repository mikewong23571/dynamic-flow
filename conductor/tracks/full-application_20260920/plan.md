# 实施计划

## 第一阶段：模块功能实现

- [~] 固定最小共享记录、调用签名与前后端操作；派发互不重叠的任务。
- [ ] 状态模块：文件持久化、工作材料、草稿与候选起点、校验、采用和保留；域内测试。
- [ ] Pi 模块：实际 SDK/端点、作者工具、节点结构输出、事件与取消；域内测试及真实协议探测。
- [ ] 前端模块：真实设计参考、统一控件与视觉、画布编辑、材料/结果/比较/对话；域内检查。
- [ ] 运行与比较模块：固定输入版本、逐项/分支/汇合、停止重试、同输入比较；先核心失败测试再实现。
- [ ] 阶段检查：各负责人交付本域测试、影响域和未测项；不作重度独立审计。

- [ ] Pi update_flow → 保存 → 快照 → 画布；节点活动与实例一致。
- [ ] 运行、比较、停止、结果续做、持久化与前端所有动作联通。

- [ ] 阶段检查：类型、构建、模块/集成检查通过，正式应用可启动。
