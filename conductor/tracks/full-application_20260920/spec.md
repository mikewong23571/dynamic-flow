# 整个应用原型实现

2026-09-20 用户授权独立完成现有十九个用户故事；本 track 将讨论稿作为本轮实现范围，不将授权误记为验收通过。

## 目标

用户不写代码，通过目标与材料建立工作、由 Pi 生成流程、在画布与对话中修改、运行并检查来源、试验候选、比较同样本、独立采用定义与保留结果、用指定产物续做、处理新材料并重新打开。

实现依据为 docs/user-stories.md 的 A1–F4、T1–T8 与 spike/tests/cases.md 的 P01–P32。功能语义和错误案例沿用当前设计，新增反例就近记录、修正调用双方，不维护假想的完美架构。

## 非目标

不建设安全/权限/隔离、通用平台、自动优化与缓存、任意代码编辑或反向分析、多节点局部试验、无限循环、生产部署。保持一个进程、本地文件、少量明确模块。

## 实施与验收

先模块功能实现，再模块接线，最后主 agent 完成产品级验收。模块开发者只跑改动域内必要测试。根 agent 固定共享交接、协调接口、实现运行和比较、启动服务并走完真实用户路线。fixture 用于可控故障和边界；真实模型用于生成、修改、比较和报告；不能互相代替。

完成要求：正式应用可通过 pnpm dev 启动，类型/构建/模块与集成测试通过，浏览器实际操作与 1440×900、1024×768 截图有记录；十九个故事与八条路线逐项记录事实、未测项和限制。视觉判断实际展示给用户，自动检查不代替用户品味判断。
