# Spec — AGENTS 驱动的模块代码骨架

用户已明确要求创建代码骨架，以模块 AGENTS.md 规定职责、目标、非目标及验收，并保留未知与修订空间。本轮授权包含必要项目导航及检查配置同步；不再就已授权的骨架工作重复确认。

## 范围

- 在正式 src 下创建最少功能目录和 TypeScript 源码占位入口；Spike 保留伪代码。
- 各模块 AGENTS 包含可独立处理的子问题、输入输出意图、依赖、目标/非目标、验收场景、当前未验证假设。
- 提供模块验收与跨模块用户路径的对应关系；全为未实现/未验收，不制造假成功。
- 将“根据实际反例修订设计”写入协作规则，不能把现在的字段/边界当成冻结架构。

## 完成标准

模块入口可被独立类型检查；所有模块有范围明确的 AGENTS；31 个设计用例及 19 个故事没有失去责任归属；关键跨模块链路有验收负责人；文档与实际目录一致。原稿、旧实验代码和本地密钥配置保持原样。

## 非目标

本轮不实现业务函数、接真实模型、搭 UI、增依赖或生成大批占位测试；不建立基类/插件/分层框架，不增加安全、权限、隔离设计。
