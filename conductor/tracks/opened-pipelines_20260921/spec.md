# 稳定的流水线切换区

用户任务：在几条流水线之间反复切换，点击与实时更新不改变导航位置。替代“最近流水线”的混合更新时间/访问排序；对应工作库维护 G2、重开 F4。

- 从库、工作项或创建入口打开新流水线，追加到末尾；再次打开只选中。
- 已打开列表不受编辑、运行、SSE 或库排序影响；标题原位更新，不截取前五条。
- 每行有独立“关闭流水线”按钮，只移除本地入口，不归档、删除、停止运行或清除草稿。
- 关闭当前项优先选右邻项、否则左邻项；最后一项关闭后进入全部流水线。关闭非当前项不改变内容与管理页位置。
- 本浏览器 localStorage 保存有序入口，刷新恢复。旧用户仅迁移原来保存的当前工作，不把库前若干项伪装成已打开。
- 库入口改为“全部流水线”。归档项移出打开列表，恢复归档不自动打开。

实现交接：useConnection 管有序入口、元数据与当前快照；controller 组合关闭与工作区状态；Sidebar 只展示和发出打开/关闭意图。继续使用 WorkSummary，不改变业务保存/API。复用现有侧栏行、Lucide X 和 shadcn Button，保持 Geist 暗色；沿用已讨论的固定导航模式和现有控件实例。
