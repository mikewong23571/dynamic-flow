# 结果总览与独立成果验收

范围：方法运行结果默认业务聚合表格、历史展开、独立运行、仅看成果、具体成果阅读与过程检查分层；不新增后端接口或更改用户数据。用户最新否定重复面包屑，正式方案使用已有页面层级及明确返回动作。

## 实现边界

- `Results.tsx` 为方法结果宿主，管理总览/成果/过程及按需业务状态读取；当前业务状态来自 `/api/items`，后台快照不抢走历史查看。
- `ResultsOverview.tsx` 复用现有 Table/Input/NativeSelect/ListPagination；`result-overview-model.ts` 投影方法内历史，编号使用工作项跨方法 runs，未运行关联不计入结果。
- `RunProcess.tsx` 承接原方法运行选择与共享 RunInspector 接线；完整 RunFocus 保持跨运行精确来源，普通运行不伪造业务项。
- 具体成果只使用既有 ArtifactValue 与方法使用动作，当前 resultId 宿主保留查找/展开/滚动；不复制运行导航。复制保留原值和明确失败反馈。
- 结果使用主空间，画布面板隐藏并保留草稿；返回列表保留查询、排序、分页、历史展开和滚动。

## 验证记录

类型与构建通过，保留既有大 bundle 提示。本轮浏览器使用私有临时目录、真实 HTTP/runtime/文件，Agent 输出为明确 fixture；真实业务独立检查只读，不调用模型。

`interim-regression.log` 是过渡检查，不能作为完成证据：动态第二次执行和空态标题仍用了旧入口假设；一个历史检查在重建 dist 时进入空白页。导航/空态断言按新产品路径更新，仍保留业务断言；最终构建稳定后重新验收。

最终稳定构建的 [18项浏览器回归](browser-regression.log) 全部通过（1.7分钟）：跨方法来源/比较/业务使用、旧取消实例及历史滚动、两尺寸大集合及非空比较、同Run双入口、普通运行重试/保留/多选续做与跨Run精确来源、动态固化/迭代、业务总览/历史编号/错误重读、集合成果状态保留与复制失败、多页/无运行项排除、业务结项但Work修订不变时重新可见刷新、主动新运行回总览且后台记录不抢走成果。[独立最终实看与三轮性能](../results-overview-review/README.md)已通过：总览218–253ms、历史展开100–101ms、成果283–299ms、过程400–450ms、返成果167–183ms、返列表149–166ms。两尺寸无pageerror或整页横向溢出。新性能口径必须分别记总览与打开成果/过程，不能用总览数值冒充旧版直接渲染详情。
