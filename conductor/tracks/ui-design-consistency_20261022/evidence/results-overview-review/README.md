# 结果层级独立验收（2026-10-22）

本轮使用本地 Playwright，只读访问 4320 的真实 CVE 工作项和业务影响分析流水线。未改变业务数据，未调用模型。最终源码、构建冻结后执行，性能期间无其他浏览器测试。

## 导航与视觉

用户指出页面已包含层级，因此取消重复面包屑。总览不增加导航行；成果和过程仅保留有明确目的的返回动作。成果进入过程后只有“返回原成果”，原成果再返回所属列表。

[最终检查](final-checks.json)覆盖 1440×900、1024×768：工作项聚合、当前未结项与执行已完成分列、全局第 3 次推进、独立成果阅读、同一运行及成果的过程定位、搜索/排序/分页设置/展开保留、编辑面板恢复、工作项跨入口返回。两尺寸无横向溢出、无页面异常、无重复面包屑。

人工查看 [窄桌面总览](final-items-1024.png)、[窄桌面成果](final-artifact-1024.png)、[过程检查](final-process-1440.png)：总览以表格为主体，成果主阅读区不夹杂运行检查控件，过程保留统一检查器；返回原成果没有重复导航行。其余最终截图以 `final-` 开头。`sample-v1-*` 和 `navigation-v2-*` 为中间设计记录，不作为最终验收截图。

## 三轮性能

[测量脚本](measure.cjs)在三次新页面中，记录点击、目标内容可见再经过两帧的时间；总览须真实业务状态加载完成，过程须精确目标成果可见。包含 Playwright 操作开销，并非纯 React 渲染耗时。timeOrigin 断言排除了重载干扰。[原始记录](final-performance.json)。

| 操作 | 三轮范围 |
| --- | --- |
| 运行结果 Tab → 业务总览 | 218–253 ms |
| 展开运行历史 | 100–101 ms |
| 历史 → 成果详情 | 283–299 ms |
| 成果 → 过程检查 | 400–450 ms |
| 过程 → 原成果 | 167–183 ms |
| 成果 → 原列表 | 149–166 ms |

本轮总览与旧版直接进入检查器的测量终点不同，不将两者当成同一性能指标比较。多页、大集合、新运行、状态刷新与失败反馈由本轮隔离浏览器回归覆盖，见上级 evidence.md；真实数据独立检查不宣称重跑模型或完成业务核实。
