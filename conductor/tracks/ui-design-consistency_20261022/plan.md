- [x] 梳理工作项详情、管理列表和编辑工作区的核心任务、主内容、定位信息及主要动作；标明重复、抢占空间和缺乏用途的信息。
  - 验证：用真实页面逐项对照 [问题基线](baseline.md)，每个删减/重排决定说明用户收益；不以组件盘点替代页面判断。
- [x] 结合 Linear、Geist、Primer 的具体实例，确定代表页面的构图和两尺寸布局；明确顶部、辅助导航、成果与阅读区域的空间关系。
  - 验证：给出可查看的布局草案或浏览器原型，以真实长报告和结构化集合检查；不增加仅用于展示的功能。
- [x] 确定精简的文字、间距、内容宽度、材质/边框、状态和操作层级规则；列出复用现有控件、调整默认值及保留专门布局的理由。
  - 验证：规则能解释代表页面的主要取舍，实际核对已有控件与 CSS 覆盖来源；不新增无法对应具体需求的抽象。

## Phase 2：完成工作项详情样板

- [x] 按整体构图重组详情：精简定位和进展区域，让成果更早出现；保留来源、状态与业务动作，处理窄桌面的导航占用。
  - 验证：两尺寸首屏清楚呈现状态、需处理事项和成果入口，并记录实际正文位置；检查历史、来源、返回、未保存条件及长滚动定位。
- [x] 整理内容层次与阅读节奏：减少重复标题/工具条/套框，统一同类卡片对齐，调整文字层级、报告宽度与区块间距。
  - 验证：逐张查看首屏、报告阅读、业务记录截图；核对 computed style，确认改动实际生效且不是将内容简单向下推。
- [x] 在现有控件体系中落实样板所需的默认值与组合，处理当前范围的兼容层和样式覆盖冲突。
  - 验证：真实 CVE 数据只读检查，非 CVE 集合与报告验证；检查键盘操作、错误反馈及原有成果交互；不为复用把不同任务做成同一页面模板。
- [x] 复测样板性能，修正隐藏内容渲染、重复更新或状态丢失等退化。
  - 验证：同环境前后各至少三次测量，保留输入与范围；运行已有大内容按需渲染与集合浏览回归。

  - 验证：两页并排检查主次、密度、对齐和控件一致性；搜索、筛选、分页和菜单仍有效。

  - 验证：实际打开并操作有内容的页面；检查画布/配置/输入/滚动/弹窗焦点，无布局或状态回退。
