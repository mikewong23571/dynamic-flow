# 前端设计语言与页面体验治理

2026-10-22。状态：已实施并完成本轮验证，结果见[evidence.md](evidence.md)。用户要求专门治理设计语言、页面呼吸感、视觉一致性与组件使用方式，并明确：**以设计师的判断设计前端，重点在设计，而不是堆砌组件或功能。**

## 目标

让用户进入页面便能看清正在处理什么、重要内容在哪里、下一步能做什么。通过构图、信息主次、空间节奏、文字和交互共同组织体验；组件是实现手段。延续现有暗色方向，先完成工作项详情这一代表页面，再把经过验证的设计规则用于其他页面。

| 用户问题 | 要形成的设计结果 | 如何验收 |
| --- | --- | --- |
| 页面抓不住重点，描述和制品全文堆满屏幕 | 主内容、当前状态、主要动作有明确主次；说明按需出现；成果能检查、比较和使用 | 走完“打开工作项 → 找到当前成果 → 检查来源 → 返回 → 使用成果”；不依靠阅读功能介绍理解操作 |
| 跳转后不知道在哪里、内容由哪个环节产生 | 定位信息稳定且精简，当前工作项、轮次、环节及来源可辨认 | 查看历史与上游后能返回原位置，选择、阅读位置、未保存输入保留；历史有明确来源和业务用途 |
| 缺乏呼吸感，正文出现太晚 | 顶部占用、辅助导航与内容比例合理；组内、区块间和主要区域的间距有区别 | 两尺寸首屏清楚呈现当前状态、需处理事项和成果入口；记录成果正文的实际位置；对照截图检查报告阅读、长行宽度和嵌套容器 |
| 一片黑，边框暗淡，卡片标题和状态错位 | 页面、内容面、浮层、选中及状态层次清楚；同类元素对齐、文字层级一致 | 同屏检查长短标题、有无成果标记及不同状态；颜色以外仍能识别状态；不靠所有区块加重边框分层 |
| 各处微调导致不一致、难维护 | 少量清楚的视觉规则与页面模式，控件默认值稳定，局部样式职责明确 | 同一操作意图在不同页面表现一致；新增同类区域可沿用规则，无需复制一串特殊覆盖 |
| 前端渲染慢 | 设计调整后保留按需呈现与流畅导航 | 同一数据和路径复测首次打开、切换和长任务；未访问的大正文不提前渲染，已查看状态不丢失 |

### 设计方式

1. 先明确用户任务，决定什么值得占据屏幕；删减重复标题、无用介绍与无关操作，再确定布局和控件。
2. 先审视整页构图与内容比例，再设计区块关系，最后统一细节。不能通过逐个美化卡片、统一加 padding 或更换组件来宣称整体设计完成。
3. 参考有具体分工：Linear 的导航与内容主次；Geist 的暗色材质和文字层级；Primer 的页头、布局与操作组织。形成一套连贯表达，不拼贴多套皮肤，不新增第二套基础组件库。
4. 沿用 shadcn/Radix 的基础交互和已有专业组件。布局服从任务；仅在结构与交互确实重复时组合共享组件。工作项、画布和对话可以布局不同，但视觉规则与操作语义应一致。
5. 先用真实内容把代表页面设计好，再推广。参考、组件清单、自动测试和截图数量均不能代替设计质量判断。

## 非目标

- 不新增业务功能，不把设计治理变成功能扩张；不引入 CVE 专用页面或依赖特定流水线字段的布局。
- 不重写应用、替换整套组件库、搭建设计系统平台、页面 DSL、万能卡片或通用配置式页面。
- 不以组件复用率、CSS 行数减少、token 数量或截图数量作为完成指标；保留有用户价值的专门布局。
- 不通过全局一键更换 CSS 层、加高优先级覆盖或加大所有间距解决局部问题；不为稀有异常增加复杂机制。
- 不改变 Work / WorkItem / Run / Definition、固定输入和历史、业务完成条件、采用方法与保留结果的语义；不扩展后端、权限或生产治理。

## 影响域

涉及工作项详情与列表、流水线库、编辑工作区、结果阅读/比较、Assistant、设置弹窗及全局侧栏。先改代表页面；共享样式每次改动检查实际调用方，避免在一个页面修好、另一个页面退化。

业务回归以 H2 进度识别、H9 跨方法历史、H10 证据和完成条件，以及既有成果检查/使用路线为主；共享控件检查覆盖打开流水线、画布选择/配置、Assistant 输入和弹窗焦点。保留错误、等待、失败与业务未完成的真实表达。

### 内容、错误和尺寸样本

- 真实 CVE 双流水线只读复查；另用非 CVE 的结构化集合与长文本报告验证同一设计，不能只为一个数据形状排版。
- 两种桌面尺寸：1440×900、1024×768。包含长短标题、有无成果、空状态、运行/等待/失败、读取错误、跨轮历史和未保存输入；使用已有状态样本，不建设异常演示平台。
- 浏览器实际操作并逐张查看截图，检查定位、阅读、空间节奏、主次、对齐、控件和反馈。构建或测试通过不代表用户认可视觉。
- 延用已有性能测量路径。历史修复后约 1.2 秒首次打开、0.18–0.26 秒切换是单次本地参考；实施前重测当前基线，实施后在相同环境重复至少三次并记录范围。明显退化必须解释、定位和修复，不把易波动的墙钟时间硬编码为浏览器断言。
- 未访问的大正文继续按需构建，集合分页、全量查找、已访问内容状态及来源返回保持有效。测试写入使用独立临时数据，用户数据不作为可清空夹具。

### 完成条件

四个实施阶段全部完成且有可复查证据：页面主次和阅读体验改善、关键操作保留、跨页面视觉规则一致、没有渲染性能回退。交付分别说明实现、自动检查、真实浏览器和性能测量的结果；用户视觉意见如实记录，不自行宣称审美认可。

2026-10-22 实施中用户追加：业务进展区的呼吸感与长文可读性优先，不为首屏正文位置把事实和解释强行挤成一行。阶段、执行、条件分组；下一步自然换行预览；报告折叠头只保留来源/时间与查看入口。

## 追加范围：状态语言与工作区性能

用户继续授权修复执行状态标签不一致，以及真实业务影响分析在流程/运行结果/比较间切换卡顿。新增明确改动点：App页签挂载边界、Results/Comparison/ArtifactValue以及独立Value渲染文件、ui.tsx状态入口、WorkflowNode与WorkLibrary的状态调用方。保持关键业务文本区分执行完成与工作项结项；不使用未知图标替代必要含义。

验收：真实B工作区同路径前后三次测量；其比较为空态，如实限定，额外用私有真实HTTP/runtime的非空比较fixture补足；大结果首次进入不全量解析隐藏正文，已选结果/运行/展开/搜索/滚动在三页签间保留，不同方法不串状态。隐藏页签不消费持续父级更新，不改变业务状态或固定输入。

## 追加范围：相同Run共享检查核心

用户指出工作项内的运行检查与流水线运行结果存在两套页面结构，要求从产品语义收敛。运行本身固定定义、输入和结果的检查含义一致；工作项与方法工作区只在外部定位和可用动作上不同。

提取已验收的工作项检查核心到results域：RunInspector负责环节/实例定位与访问状态，RunArtifact负责产物/输入/来源/执行记录，固定定义与精确结果定位模型同域维护。输入为真实运行/定义/来源快照，不制造WorkItem或引入通用页面DSL。WorkItemExecution保留跨方法轮次、证据/条件及成果比较；Results保留运行选择、方法候选、保留/续做和重试。所有普通试验运行也能使用同一核心，原固定来源与错误必须如实呈现。

共享检查不得撤回已验证的按需渲染、inactive页签冻结与Work身份隔离。新增回归验证同Run跨入口检查一致、普通无WorkItem运行与比较、选择/展开/scroll保留；实际新结构的截图/性能结果与上一轮证据分别记录。

## 最新追加：对象、状态与操作优先（已完成）

运行主工作面不再插入实现术语说明块或重复的动态节点说明列表。真实冻结依据与环节要求复用共享“输入与依据”按需查看，两个入口保持一致；动态候选动作就近保留为“保存为候选做法”，协议不变。成果比较的必要对齐口径归入表头/提示；真实报告、错误、过期警告和必要空态指引保留。范围仅运行/成果比较及相关指南，不扩展全站文案重写。验收见最新6项回归与两尺寸独立实看。

## 追加：流水线运行结果的信息层级

输入为当前方法的真实Run/固定Definition，GET /api/items提供当前业务状态；Run.workItem仅表示冻结身份，不能推断业务结项。默认表格按业务id聚合同一方法内全部历史运行（包括工作项已更换方法后的历史关联），只列在本方法实际运行过的项；当前关联但没有运行不属于结果。没有WorkItem的运行独立列出，按scope/effectMode标注单节点试运行或独立运行。

输出层级为工作项表格/仅看成果→具体成果或过程。成果来自显式最终输出、非规划/中间且实际有内容的NodeResult，不解析业务结论。具体成果复用ArtifactValue与现有方法使用动作，查看过程才使用RunInspector/RunArtifact。表格查询、状态、排序、分页、展开和滚动在返回时保留。数据读取失败保留上次内容、明确当前业务状态不可用并可重读，不凭旧Run伪造状态。采用明确返回列表/原工作项动作，不重复页签和表格已有层级；来源追溯有返回原成果。

方法结果/成果默认主内容宽度，编辑画布恢复原面板与草稿。既有方法/业务动作、固定历史语义、完整RunFocus交接与按需挂载保持。仅扩展必要client模块及私有fixture，不改后端或用户数据。

### 最新取舍：不重复表达层级

用户指出标题、页签和展开行已表达层级，取消新增面包屑及仅为它创建的分组详情路由。总览直接呈现表格；具体成果/过程用单个明确返回列表或原工作项入口，来源追溯保留返回原成果。返回仍须保留表格筛选、排序、分页、展开和滚动；成果查看过程后保留阅读状态。
