# 视觉锐利度提升

用户反馈：当前暗色界面与 Vercel 自家产品相比「黑成一片」、层次不分明、颜色不锐利；重点改善侧边栏与中间编辑区域观感。延续 geist-workspace track 的方向，不改组件结构。

诊断（以 token 值与截图实测为准）：

- 底色 #0a0a0a 非纯黑，相邻灰阶差小，大面积铺开糊成一片；Vercel 用 #000 底 + 边框/极小填充差分层。
- 边框实色 #2a2a2a 偏重，所有盒子被均匀描边；Vercel 用 rgba(255,255,255,0.08–0.14) alpha 边框。
- 蓝色 --accent 用于选中节点、聚焦、tab、开关等多处；Vercel 主操作白色，蓝色仅焦点与链接。
- 标题与正文同为 #ededed，层级拉不开；分组靠分隔线与色块而非间距；modal 阴影偏重。

范围：

- P0 重调 styles.css 暗色 tokens：纯黑底、alpha 两级边框、纯白标题、减阴影；表单控件用 line-strong。
- P1 侧边栏：分组标签、hover/selected 用白 alpha、右分隔线 alpha。
- P2 中间编辑区：tab/工具条选中态去蓝、节点卡片边框 alpha、选中描边收敛、开关去蓝。
- P3 全局细节：focus ring 统一、modal/popover 边框与阴影、滚动条。
- 每阶段 1440×900 与 1024×768 实际操作与前后对比截图；浏览器回归通过。

非目标：不改 IR、执行语义、组件结构、交互逻辑或持久化；不引入新依赖或主题平台；不以测试通过代替用户审美认可（最终观感由用户判断）。
