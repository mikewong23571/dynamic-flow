# 本轮整页设计与自审

主代理独立完成。设计原型在[design/index.html](design/index.html)，以view=home/result/flow/history/children/method等参数切换；全部内容明确为假设。两尺寸整页图在同目录。它们是构图产物，不是模型或产品功能证据。

## 选定的构图

- 首页是稳定根入口：共享应用导航，上方需求/文件开始区，下方继续处理列表；不再另设与工作项重复的仪表盘。
- 工作项与流水线使用同一74px页头、46px导航、主区和可调宽度侧栏。返回在页头左侧，不能另占顶部横条。窄屏会话展开覆盖，工作项收起时保留同一Composer。
- 工作项默认流程是实际图。常显仅就近执行状态/来源、编辑入口和一个当前运行控制。手工选择/添加方法与节点只在明确编辑后出现；配置进入与Assistant共用的侧栏，不挤出第三栏。
- 成果由交付声明的标题/列形成业务视图。少量视图直接导航，较多视图收进选择器；数据与选择始终绑定真实交付。
- 子项任务一处标题，空态只有必要的建立入口。非空才出现少量列表动作；筛选主动展开，未匹配仍保留清除入口；只有超过一页才分页。
- 记录一条日期分组时间线，运行是其中一次事件，时间/状态/来源与正文同行；不再另列执行记录。

## 设计检查及取舍

已查看首页、流程、记录、子项空态和成果两尺寸等代表整页。首页输入和继续区有清楚主次；窄屏成果会话停靠，保持表格宽度；子项空态移除零项分页/重复标题；记录将来源收进对应事件。对照时发现方法页设计稿重复运行控制，已改为保留页头的一处；不照搬这份示例的假设图到产品源码。

复用现有shadcn/Radix控件、Management列表/分页、Assistant/Composer、ReactFlow、MaterialDialog、RunInspector。新增共用骨架只服务已有两个工作区；首页复用原创建/上传服务，创建表单与首页共用相同文件保存函数。没有增加布局DSL、任意UI树或新的调度器。

| 现场 | 设计落点 |
| --- | --- |
| 首次/无工作项 | 开始区保留，继续区简洁空态，无零项分页 |
| 有待办/筛选无结果 | 实际列表；主动查找，清除筛选仍可达 |
| 加载/读取失败 | 开始区不消失；列表局部骨架或真实错误/重试，不冒充空列表 |
| 新项/正在规划 | 需求与材料可查，Assistant真实会话；流程尚未形成时不展示假计划 |
| 有流程/有成果 | 读真实图/交付；手工编排为明确模式，视图由声明形成 |
| 长会话/长标题 | 消息独立滚动、Composer固定可达；标题截断且完整目标可打开 |
| 子项空/非空/过滤空 | 空态、列表、无匹配分别构图；阶段交接按需进入 |
| 等待/错误 | 原因与当前必要动作就近呈现，保留输入，不用成功标签替代 |

自审认为该构图可进入代表实现；用户审美认可尚未声明。具体实现后仍须E阶段逐屏修正，不能用这份原型跳过真实内容检查。原型不声明已有业务操作或模型成功。

## 实施后的逐屏修正

已在两尺寸实际页面检查首页、流程、声明成果、输入、记录、条件、长会话、子项三种现场和长标题，证据见evidence/personal-implementation、personal-browser。默认流程移除工具清单，子项空态移除重复标题及零分页，日期/内容/来源合为同一事件。窄屏主动收起覆盖会话后保留真实Composer，图可完整阅读，声明成果切换保留选择。真实模型两call图检查发现缺边：客户端端口逻辑与shared分叉，已删除重复实现，复验及实际图完整。静态方法窄屏覆盖面板补不透明背景，避免内容透过；设计图和实际产品证据分别存放。当前内部自审完成，用户尚未明确接受新画面。
