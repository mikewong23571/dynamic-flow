# 从材料加工转向业务工作项的持续推进

用户已授权以新的生命周期标准设计故事并完成实现。验收来源：[H1–H11 与 L1–L5](../../../docs/workitem-stories.md)。

核心改变：Work 保留为处理方法工作空间；独立 WorkItem 承载业务身份、目标、完成条件、证据和进展，关联多次固定版本 Run。IR 增加显式业务里程碑与持久等待，保留现有计算节点并补齐有限并发与输入输出 schema 校验。工作项不因运行成功自动完成。管理总览面向阶段、等待原因、下一触发与业务更新时间。

存储继续使用单进程本地文件的原子替换；工作项独立文件，等待与节点检查点保存在 Run。现有有限声明图能记录恢复点，不引入任意函数调用栈回放。进程启动恢复持久等待和已到期任务；不确定外部调用需显式继续，不承诺恰好一次副作用。先通过真实重启反例验证，不建设分布式引擎。

非功能：延续 Geist 暗色和现有 Radix/React Flow/assistant-ui；业务表单清楚、少介绍文案；模块按工作项、运行器、UI 拆分。不硬编码 CVE 分类结论，不新增权限治理。
