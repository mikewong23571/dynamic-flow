# 工作项进度总览与单项推进状态

[规格](spec.md) · [实施计划](plan.md) · [验证记录](evidence.md) · [元数据](metadata.json)

## 目标

用户无需逐个阅读 Agent 对话或运行日志，就能知道整体还剩多少工作项、每件事推进到哪里，以及哪些需要介入。

- 工作项页增加可点击的数量汇总，查看未完成与已完成，以及待推进、推进中、等待中、需处理的分布。
- 单项详情并列显示业务阶段、当前执行、最近成果、阻碍和下一步，保留完成条件、证据与历史。
- 正式工作项执行中的 Agent 可直接报告进展，复用工作项保存与历史，不要求先在画布中配置全部里程碑。

## 范围与状态

本 track 为原型增量功能；2026-10-21 已完成实现、本轮测试与真实模型/浏览器验证，证据与适用边界见验收记录。沿用 `conductor/tracks/`、现有文件存储、HTTP 轮询和控件，不迁移 Conductor，不新增基础设施或依赖。

基于已实现的 [工作项生命周期](../workitem-lifecycle_20260920/index.md)，扩展 H2 总览与 H11 外部观察，保持 H3/H4/H10 的固定运行、试验隔离和显式结项边界。相关 track 是背景依据，不把历史验收视为本次通过。
