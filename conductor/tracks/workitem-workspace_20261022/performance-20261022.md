# 渲染性能与视觉层次修复

2026-10-22。用户在实际使用中报告前端渲染很慢、环节卡片标题/状态/成果标记不对齐、颜色与边框缺少层次。本轮直接复现并修复上述问题，保留检查与导航状态。

## 复现与原因

用本地 Playwright 打开实际 CVE 工作项，数据为已执行完成的 A/B 两条流水线。A 快照约 848 KB、B 快照约 1.48 MB，HTTP 读取约 0.1–0.3 秒。旧页面首次打开需 7.8 秒，连续切换环节需 7–11.5 秒，主要阻塞发生在浏览器。

此前仅用 hidden/CSS 隐藏标签页、已访问实例与 details 正文，却仍解析未查看的 Markdown、递归创建嵌套内容，并在父组件更新时重复处理。详情内还持续刷新不可见的工作项列表，相同数据替换对象引用使大内容重复渲染。

## 修复

- 未访问标签页、工具记录、固定输入、证据和嵌套正文首次查看才创建；已查看内容保留状态。
- 对稳定的结构化值复用渲染；集合投影只在数据、查找或排序变化时计算，空查询不逐项序列化全文。
- 集合每页 50 项，查找覆盖全部条目；表格只显示短预览，完整值在条目检查中保留。
- 详情只轮询当前工作项；相同业务修订与执行摘要保留已有对象。方法快照无新修订时保留引用，执行期间只轮询当前执行的方法。
- 卡片统一为两行标题空间与底部状态行，成果标记同排显示。长短标题、不同状态与成果角色不再改变卡片高度。
- 使用现有主题的 paper/surface/accent-soft 和 line-strong，区分页面、执行容器、内容面板与选中项；卡片边框增强，选中项使用蓝色背景与边框。未改全局状态色。
