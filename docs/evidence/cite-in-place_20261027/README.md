# 逐项阅读中的验收证据收集

2026-10-27。此前从成果引用条件会进入整体验收，打断逐项检查；现在收集证据与整项确认分开。

## 实际实现

- 成果工具区新增 WorkItemCitation：明确选择证据对应条件并加入验收证据。单条件自动选中；所选目标在同项不同实例间保留。反馈行预留位置，引用成功保留正文几何与阅读位置，不切页、不自动换实例。已有引用显示已加入，重复操作不新增记录。
- 复核弹窗第一项改为“加入验收证据，继续检查”，普通引用菜单同样就地引用；最终验收页由人主动进入。RunInstancePicker 复用真实列表增加上一项/下一项，边界禁用，不创建另一份复核队列。
- HTTP citeCriterion 串行重读最新工作项，仅追加明确条件的精确 CriterionReference 和来源说明；不提交整个旧条件数组，不改变 met、不结项、不改 Run。重复来源幂等，目标删除/改名、外项未交接来源、无效位置和已结项均拒绝。validateReference 返回真实节点/实例用于跳转。
- WorkItemDetail 将新引用合并进同文本的本地未保存条件，保留已有文字、勾选和其他条件草稿；文字改动尚未保存时要求先保存。引用失败显示在当前成果并允许重试；组件离开后的迟到响应不抢导航，旧响应不倒灌新版本。
