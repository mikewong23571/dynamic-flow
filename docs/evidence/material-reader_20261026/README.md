# 固定框架的材料阅读器（2026-10-26）

上版弹窗只有max-height，实际高度由当前内容决定；查看结构化内容与原始数据时，外框会随内容长度变化。卡片自带弹窗与历史/报告引用的旧Modal又是两种框架。

本次统一为MaterialDialog：960×720的阅读窗口按视口收缩，标题/材料图标/引用编号/字符数组成固定头部，下方固定查看方式、来源和复制原文操作栏。正文是独立滚动区，切换模式保持外框、标题栏和操作栏的几何不变；两种正文视图按需创建，各保留阅读位置。原始数据直接使用保存的text，复制同样保留原文。缺失材料仍显示真实不可用状态。保留Radix焦点管理、嵌套对话框返回及来源跳转前关闭行为。

材料卡片、方法与工作项输入选择、子项带入、业务历史、报告引用及运行来源使用同一阅读框架；各调用方不再拼接自己的ArtifactValue阅读器。没有新增业务模型或修改材料正文、运行数据。
