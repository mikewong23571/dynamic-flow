# 暗色界面可见性修复（2026-10-26）

本次处理小字过暗、控件边界过淡、画布关系聚焦过度淡化及禁用按钮文字不清晰四类问题。

## 改动

- `--subtle` 从 `#666666` 提亮为 `#929292`，黑底对比度从约 3.66:1 提升到 6.75:1；在 `#141414` 表面上约 5.92:1。
- 新增 `--control-border: #707070`，供原生控件、Tailwind `border-input` 和描边按钮使用。与 `#141414`、`#1f1f1f` 的对比度分别约 3.72:1、3.33:1。页面结构线和卡片边界仍使用原有 line 变量。
- 画布非关联节点透明度从 0.4 调整到 0.9，非关联连线从 0.18 调整到 0.85；关联关系仍以蓝色和更粗的线条强调。
- 禁用按钮保持不透明，使用 `#a1a1a1` 文字和 `#141414` 背景，对比度约 7.13:1；保留原生禁用行为，移除按钮 primitive 中的整体透明度样式。

对比度为按源码颜色计算的静态值，不代表所有页面、缩放比例及设备均已完成可访问性验收。
