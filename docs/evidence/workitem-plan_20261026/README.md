# 处理方案初步原型（2026-10-26）

## 实现范围

工作项新增“处理方案”页签，通过一个前端组件 `WorkItemPlan` 读取现有流水线做法。展示真实方法名称、当前采用/候选版本、问题认知、已知与未知、约束和依据、步骤职责/安排理由/完成要求、实际后续关系及预期成果。未填写的语义字段不生成内容，步骤排列不声称执行顺序。

查看默认跟随流水线当前采用的版本，未采用时显示候选；切换候选预览不采用版本。编辑直接复用现有画布，绑定当前工作项上下文，明确不自动选择业务材料或发起模型调用。返回工作项后重新读取，候选视图显示新保存的草稿；已采用版本不被改写。输入准备、选择/更换方法及生成方法全部连接已有界面。工作目标弹窗只展示目标，方法操作集中到方案页签。

未新增后端接口、持久方案对象、执行状态或通用抽象，没有增加依赖。进入/返回页签时刷新，没有添加实时订阅；完整的表达式、schema 及步骤配置仍在画布中编辑。默认内容页及父项的子项导航规则保持现有行为。

## 入口可见性修正

后续反馈表示只看到“生成处理方法”，未找到方案。只读检查确认托管前端已返回方案页签代码；此前入口只在长正文下方，容易被推到首屏之外。现于详情右上角始终提供“查看处理方案”，点击后切换并滚动到固定页头下方。重新通过类型检查、构建和方案/报告浏览器用例（各 4 passed，共 8 项）。新增场景用重复 80 次的长阻碍正文将页签推到视口之外，断言顶部入口可见，点击后方案页签进入固定页头下方 48px 范围内。定位验证还发现详情在 flex 容器中被压缩时会使固定页头提前滚出；已禁止详情收缩，并为加载中的方案保留可定位的最小高度。托管服务已返回新按钮代码，未重启服务或修改用户数据。截图：[1440](header-entry-1440.png) / [1024](header-entry-1024.png)。

上述强制定位是早期交互记录，现已根据“切换时业务背景消失”的反馈取消。当前入口与手动页签切换不主动滚动，保留业务阻碍、下一步和来源的位置；父项方案也已补齐真实子项分工。当前行为及最终验证见 [父项方案与共享背景记录](../parent-plan_20261026/README.md)。
