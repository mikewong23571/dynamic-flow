# 当前推进情况与报告依据交互（2026-10-26）

## 实际改动

工作项详情直接展示业务阻碍与下一步的完整正文，移除箭头、折叠和三行截断；阻碍以细黄线强调，报告来源与时间作为元信息展示。

“查看依据”复用现有 Radix Dialog，呈现右侧面板，显示真实报告内容、报告时间、来源、阶段、阻碍、下一步与引用材料。“查看相关材料”只在报告引用了实际存在的本项材料时显示，直接聚焦面板的材料区，材料正文复用现有检查弹窗。有固定运行来源时提供对应成果入口，复用现有运行、环节、实例定位及返回原视图的路径；外部报告没有运行来源时不显示该入口。不从报告文字推测子项或生成额外业务动作。

来源仅归属到与当前阻碍及下一步相符的报告，避免把后来无关记录作为其依据。打开面板后保留所选报告与材料引用，轮询更新或清除当前阻碍时不替换面板内容；关闭后恢复入口焦点，入口已消失时聚焦推进概览。

产品代码：`WorkItemProgress.tsx`、新增 `WorkItemReport.tsx`、`WorkItemDetail.tsx` 与 `WorkItemWorkspace.css`。没有更改业务数据、报告存储或执行语义。
