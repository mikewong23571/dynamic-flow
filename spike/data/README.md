# 本地工作文件目录

这里只说明将来的布局，未生成任何真实工作数据或 API Key。实际实现使用一个本地 data 路径，不把用户工作内容作为示例提交。

```text
work-id/
  work.json             目标、材料、草稿/采用定义 ID、视图、运行/结果、比较、消息
  definitions/
    definition-id.js   应用生成的不可变 JS 子集定义
```

定义文件是同一份 IR 的保存表示；work.json 只存引用，不再存第二份权威定义。每次语义修改写一个新定义，再更新工作索引；坐标变化只改视图。运行输入/产物保存在工作记录中，不引用可能被改写的外部数据作为唯一依据。
