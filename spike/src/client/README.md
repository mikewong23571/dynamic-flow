# 前端目录：要实现什么

主说明：[工作区伪代码](./workspace.pseudo.md)。功能对应所有故事，布局不按技术组件分 Tab。

| 将来的文件/组件 | 需要做的事 | 接口与验收 |
| --- | --- | --- |
| Workspace | 创建/打开工作、共享选中与运行上下文、订阅状态、错误和未保存提示 | work/read + subscribe；P01/P07/P21/P23 |
| WorkflowCanvas | 节点与连接映射同一草稿，增删连线、定位问题、显示真实节点状态 | flow/saveDraft/saveLayout；P03–P06 |
| NodeInspector | 修改任务/参数、查看输入来源与实例；局部问题就地说明 | 同一 saveDraft；P05/P10 |
| Results | 材料确认/样本选择、结果详情、报告复制、显式产物输入预览 | work/keep/continue/report；P11/P19/P20 |
| Assistant | assistant-ui 对话、固定发送时上下文、修改成功/失败反馈 | requestEdit；P02/P12/P13/P26 |
| Comparison | 同样本对齐、定义结构变化、过期标记、独立采用与保留 | trials + flow/adopt + work/keep；P14–P18/P27 |
