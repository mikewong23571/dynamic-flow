# 后端目录：要实现什么

一个 Node/Hono 进程，按当前功能直接拆文件。没有 controller/service/repository 三层套壳。

| 文件 | 待实现职责 | 验证重点 |
| --- | --- | --- |
| [work](./work.pseudo.md) | 目标与材料、成功产物选择、续做输入、报告读取 | P01/P10/P11/P18–P20 |
| [flow](./flow.pseudo.md) | 草稿更新、节点级问题、视图另存、采用/放弃 | P04/P05/P13/P17/P18 |
| [runs](./runs.pseudo.md) | 全流程与单节点同路执行、分支/逐项/合并、停止与重试 | P06–P09/P14/P28 |
| [assistant](./assistant.pseudo.md) | Pi 生成/修改和节点工作、配置端点、结构结果、取消 | P02/P12/P13/P24/P26 |
| [trials](./trials.pseudo.md) | 固定两侧和输入、顺序试验、停止整个比较、过期判断 | P15/P16/P27/P28 |
| [files](./files.pseudo.md) | 实际保存、状态推送、重开与启动后中断标记 | P21–P23 |

待办：

- [ ] 在未来 server 入口接入这些具体函数；HTTP 返回异步 ID，SSE 首次与重连发送工作快照。
- [ ] 先落地两节点执行和本地文件，给真实输入产生真实结果。
- [ ] 实现定义/输入固定、草稿起点检查、停止前后检查，保持所有入口走同一路径。
- [ ] 接入比较与结果复用，按测试补齐失败/取消/保存边界。
- [ ] 读取现有根目录 .env.local，逐协议验证真实端点。SDK 参数在实现时核对，不把伪代码照抄成假 API。

非功能重点：一个工作只执行一条链；小规模数据直接文件保存；完成状态有事实依据；出错可检查/重试。暂不引入数据库、消息队列、调度平台或业务分类规则引擎。

具体内部调用与每个文件的第三方依赖见 [依赖清单](../../pi-canvas-dependencies.md)。server 入口负责 HTTP/SSE，files 不直接依赖 Hono；Pi 事件在 assistant 中补齐会话/节点身份。
