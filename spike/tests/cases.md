## 用例写法示例（仅为伪代码）

```text
P08 停止后迟到的结果：
  Given 活跃节点的模型调用停在一个可控等待点，下一节点尚未开始
  When 用户点击停止，随后模拟模型返回成功
  Then Run 是 cancelled；迟到输出不作为成功结果保存；下一节点调用次数为 0
  And 已完成的旧结果仍可读

P19 选定产物续做：
  Given 旧 r1 有 F01/F02/F03，新 r2 只有修正的 F01
  When 选择 r2.F01、r1.F02、r1.F03 并运行报告节点
  Then 新 Run 的输入值与来源恰好等于上述选择，不读取“每条材料的最新结果”

P13 模型响应过期：
  Given Assistant 的请求基于 draft=d1，用户手动保存了 d2
  When 旧请求带着 expectedDraftId=d1 返回提案
  Then 不修改 d2；提案有明确过期提示；没有自动创建并采用第三个分支
```

## 测试分配

业务函数用小型测试覆盖输入固定、依赖执行、版本、比较和采用；模型测试替身只提供等待/失败/固定返回，不替代真实验收。HTTP + 文件联测覆盖保存重开、取消和断线重连。浏览器复走 T1–T8；真实模型补齐 P02/P12/P24 及 T1/T3/T5。不逐组件追求覆盖率，也不测试伪代码文本“包含某个关键词”来宣称业务正确。
