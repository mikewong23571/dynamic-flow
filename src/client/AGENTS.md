# 工作区前端

适用本目录。当前仅源码入口，尚无正式 UI；继承 src/AGENTS.md。

## 职责与目标

承载 A–F 故事的实际操作。一个工作区共享工作、选中节点、样本、运行版本和候选上下文；按任务组合画布、配置、结果、对话和比较。

用户要能不写代码完成：创建任务、改流程、查看执行、定位问题、少量试验、采用做法/保留结果、续做与重开。

## 非目标

不建设通用页面 DSL、自由停靠平台或独立前端业务副本；不从自然语言推断图变更，不在浏览器调用 Pi，不复制旧 Spike 的廉价视觉。

## 入口与依赖

入口预留为 Workspace.tsx；随着实际需要再拆 WorkflowCanvas、NodeInspector、Results、Assistant、Comparison。不是先建六个空页面。

依赖服务端的具体操作与状态快照，通过 shared 类型交接，不直接 import server 执行代码。外部复用 React、@xyflow/react、assistant-ui、shadcn/Radix/Tailwind/Lucide；Markdown、表格、分栏按内容需要使用。详见 [依赖说明](../../spike/pi-canvas-dependencies.md) 和 [交互伪代码](../../spike/src/client/workspace.pseudo.md)。

## 验收计划

- [ ] P01–P05/P10/P11：目标和材料可输入，流程可读可改，局部错误可修，长结果和报告可读可复制。
- [ ] P12–P19：对话固定发送上下文；比较输入/版本正确；过期可辨；采用与保留独立。
- [ ] P07–P09/P21/P23：运行、停止、失败、重开与断线状态真实，不丢未提交输入和必要选择。
- [ ] P29–P31：工具实改后画布与 Inspector 更新；工具活动属于正确实例；新定义快照不重置视口，删选中节点后无悬空详情。
- [ ] P25/T8：研究真实成熟界面、统一视觉方向，在 1440×900 与 1024×768 运行 T1/T3/T5 并提供截图和用户反馈。

模块实现者负责把上述行为连接到后端验证；静态页面、组件安装或 mock 事件不算完成。最终 T1–T8 由当前产品交付任务整体验收。

## 假设与未知

画布主入口已经确定；具体布局、面板密度、结果呈现及大图体验未确定。不要把当前伪代码布局当成已获用户认可；先做真实代表页面，根据反馈迭代，必要时调整组件边界。本清单不穷尽未知。
